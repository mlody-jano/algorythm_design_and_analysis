# Algorythm Desing and Analysis

## Introduction

Repository containing projects done during consecutive classes of **_Algorythm Design and Analysis_** course, which was responsible for providing students with a grasp understanding of how algorythms work, how to properly write optimal algorythms, and much more.

## Tech stack
- Language - **C++** (for general logic), **Python** (data visualization and generation)
- Tools - **CMake** (for easier compilation of projects)

## Projects Overview

The repository consists of three main projects:

### 1. Project: Sorting algorithms (`mergesort()`, `quicksort()`, `introsort()`)
First project contains own implementations of 3 well-known sorting algorithms, done to better understand effective sorting concepts. The following sorting algorithms consisted of:
- `mergesort()`
- `quicksort()`
- `introsort()`

### 2. Project: Graph algorithms (Bellman-Ford algorithm for SSSP)
Second project contains own implementation of Bellman-Ford algorithm for **_single-source shortest path problem_** (SSSPP).

### 3. Project: Tic-Tac-Toe using `minmax()` algorithm with alpha-beta pruning
Third project contains own implementation of Tic-Tac-Toe game with user-specified parameters. Game uses `minimax()` algorithm to simulate the AI player, effectively enabling users to play agains computer simulated player. Enables to specify the depth of search for `minmax()`, to enable for tweaks in how AI operates.
